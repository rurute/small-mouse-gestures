# 手動テストチェックリスト

ユニットテスト（`npm test`）では検証できない、実ブラウザ依存の挙動を確認する。
コードを変更したら毎回通すこと。

## 準備

1. `npm test` が全件パスすることを確認する
2. `chrome://extensions` で拡張をリロードする
3. `https://ja.wikipedia.org/` を開き、リンクを 1 回クリックして履歴を作る

## 誤爆と状態残留

- [ ] 動かさずに右クリック → 通常のコンテキストメニューが出る
- [ ] ジェスチャを実行した直後に右クリック → コンテキストメニューが出る（抑止フラグが残っていない）
- [ ] ロッカーを撃った直後に右クリック → コンテキストメニューが出る
- [ ] リンクの上でロッカー（右押しながら左クリック）→ リンクが開かず、戻るが実行される
- [ ] 画像の上で右ドラッグ → 画像のドラッグが始まらず、ジェスチャが実行される
- [ ] テキストを左ドラッグで選択してから右クリック → ロッカーが発火せず、メニューが出る
- [ ] 右ドラッグ中にウィンドウ外でボタンを離す → 状態が残らず、次のジェスチャが正常に動く
- [ ] 右ドラッグ中に Alt+Tab で別ウィンドウへ → 戻ってきても状態が残っていない
- [ ] 右ドラッグ中に ESC → 何も実行されず、離してもメニューが出ない
- [ ] 未割当の軌跡（例: 大きく斜めに往復）→ 何も起きない

## アクション

- [ ] 左 → 戻る
- [ ] 右 → 進む
- [ ] 上 → ページ最上部へ
- [ ] 下 → ページ最下部へ
- [ ] 下→右 → タブが閉じる
- [ ] 下→左 → 閉じたタブが復元される
- [ ] 右押しながら左クリック → 戻る
- [ ] 左押しながら右クリック → 進む

## サービスワーカーのサスペンド

- [ ] 拡張カードで Service Worker を停止させてから「下→右」→ タブが閉じる
- [ ] しばらく放置してから「下→左」→ タブが復元される

## 表示

- [ ] ドラッグ中に軌跡が描かれる
- [ ] 認識結果が「L → 戻る」の形で表示される
- [ ] 未割当の軌跡は「◯◯ → 未割当」と表示される
- [ ] 離すと軌跡が消え、ラベルは少し残ってから消える
- [ ] ページを下までスクロールした状態でも軌跡が正しい位置に出る
- [ ] オーバーレイがページの操作を妨げない（リンク・ボタンが普通に押せる）

## 設定

- [ ] 割当を変更して保存 → ページをリロードせずに反映される
- [ ] 記録枠で新しいジェスチャを記録して追加できる
- [ ] 既存ジェスチャと同じものは記録しても追加できない
- [ ] 「既定に戻す」で初期状態に戻る
- [ ] 不正な閾値（0 や空欄）を保存すると既定値に補正される

## 動作しないことを確認するページ

以下では**ジェスチャが効かないのが正しい挙動**（Chrome の制約）。
エラーが出ていないことだけ確認する。

- [ ] `chrome://extensions`
- [ ] Chrome ウェブストア
- [ ] PDF ファイルを直接開いたタブ
- [ ] 新しいタブページ
