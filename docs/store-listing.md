## 拡張機能名

```
small mouse gestures
```

## 説明（manifest.json の description・132 文字以内）

```
ブラウザをマウスジェスチャで操作します。右ドラッグで戻る・進む・タブの開閉・スクロールを実行。閲覧履歴も URL も読まず、外部通信は一切ありません。
```

75 文字。`manifest.json` の値と一致させること。

## 詳細説明

```
右ボタンのドラッグでブラウザを操作するマウスジェスチャ拡張です。

■ 既定のジェスチャ

右ボタンを押しながらドラッグします。

  左        戻る
  右        進む
  上        ページ最上部へ
  下        ページ最下部へ
  下 → 右   タブを閉じる
  下 → 左   閉じたタブを復元

ロッカージェスチャ:

  右ボタンを押しながら左クリック    戻る
  左ボタンを押しながら右クリック    進む

ドラッグ中に Esc キーを押すとキャンセルされます。

■ 設定

オプションページから、ジェスチャとアクションの割り当てを変更できます。
新しいジェスチャは、記録枠の中で実際にマウスで描いて登録します。認識には
本番と同じコードを使っているため、記録できたジェスチャは必ず動作します。

ジェスチャと判定する移動距離、軌跡の色と太さも調整できます。

■ 権限とプライバシー

閲覧履歴、URL、ページの内容を一切読み取りません。tabs 権限を要求していないため、
そもそもタブの URL やタイトルにアクセスする手段を持ちません。

外部への通信を一切行いません。取得するのはマウスのボタン状態と座標のみで、
方向の判定に使ったあとは保存も送信もしません。

保存するのは設定内容だけです。Chrome の同期ストレージに保存されるため、Chrome の
同期機能を有効にしている場合は他の端末とも共有されます（Chrome の機能によるもので、
この拡張機能が独自のサーバーへ送るわけではありません）。

■ 動作しない場所

以下では Chrome がコンテンツスクリプトの実行を許可しないため、この拡張に限らず
どのマウスジェスチャ拡張も動作しません。

  ・chrome:// で始まるページ（設定、拡張機能管理、履歴など）
  ・Chrome ウェブストア
  ・PDF ビューア
  ・新しいタブページ
  ・他の拡張機能のページ

また、ページに埋め込まれた iframe の上で開始したジェスチャは動作しません。

■ 対象環境

Windows 版 Chrome。コンテキストメニューの発火タイミングが OS によって異なるため、
macOS と Linux では右クリックメニューの抑止が正しく動作しません。
```

## 単一用途の説明

```
マウスジェスチャによるブラウザ操作。ユーザーがウェブページ上で行うマウス操作を
認識し、対応するブラウザ操作（履歴の前後移動、タブの開閉、スクロール）を実行します。
```

## 権限の正当化

### storage

```
ジェスチャとアクションの割り当て、認識のしきい値、軌跡表示の設定を保存するために
使用します。保存先は chrome.storage.sync のみです。Chrome の同期機能が有効な場合、
Chrome 自身の仕組みによってユーザーの Google アカウントを通じて端末間で同期されますが、
この拡張機能が独自のサーバーへ送信することはありません。保存される値は設定のみで、
閲覧に関する情報は含まれません。
```

### sessions

```
「閉じたタブを復元」アクションの実装に chrome.sessions.restore() を使用します。
セッション情報の読み取り、保存、送信は行いません。
```

### ホスト権限 `<all_urls>`

審査で最も説明を求められる項目。

```
マウスジェスチャは、ユーザーが任意のウェブページ上で行う操作です。どのサイトで
行われるかを事前に限定できないため、すべてのページにコンテンツスクリプトを挿入し、
マウスイベントを監視する必要があります。

取得するのはマウスのボタン状態と座標のみです。ページの内容、URL、タイトル、
閲覧履歴の読み取りは一切行いません。実際、この拡張機能は tabs 権限を要求しておらず、
タブの URL やタイトルにアクセスする手段を持ちません。取得した座標は端末内での
方向判定にのみ使用し、保存も送信もしません。
```

### リモートコード

```
使用しません。すべてのコードは拡張機能パッケージに同梱されています。
難読化、minify、バンドルのいずれも行っていません。
```

## データ利用の申告

すべての項目で「収集しない」を選択する。

根拠: ソースコードに `fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon` が
一つも存在しない。次のコマンドで確認できる。

```bash
grep -rnE "fetch\(|XMLHttpRequest|WebSocket|sendBeacon" src/ || echo "外部通信なし"
```

## 提出用パッケージ

```bash
python3 tools/package.py
```

`dist/small-mouse-gestures-<version>.zip` を作成する。同梱されるのは
`manifest.json` と `icons/` と `src/` のみ。

同じバージョンの ZIP がすでにある場合は中断するので、再提出のときは
`manifest.json` の `version` を上げること（ウェブストアは同一バージョンの
再アップロードを受け付けない）。
